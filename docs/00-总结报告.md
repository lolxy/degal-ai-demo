## 七、二次开发指引

### 7.1 后端开发

- IDE导入：IDEA打开 `D:\projects\RuoYi-Vue-Plus`
- 启动类：`org.dromara.DromaraApplication`（ruoyi-admin模块）
- 配置文件：`ruoyi-admin/src/main/resources/application-dev.yml`
- 代码生成器：系统工具 → 代码生成

### 7.2 前端开发

- IDE导入：VSCode打开 `D:\projects\plus-ui`
- 启动命令：`npm run dev`
- 配置文件：`.env.development`、`vite.config.ts`
- API代理：`/dev-api` → `http://localhost:8080`

### 7.3 技术栈

- 后端：Spring Boot 3.5.14 + MyBatis-Plus 3.5.16 + Sa-Token 1.45 + Redisson 3.52 + Undertow
- 前端：Vue 3.5.30 + TypeScript 5.9 + Element Plus 2.13 + Vite 7.3 + Pinia 3.0

## 八、注意事项

1. Redis密码为运行时设置，重启后需重新设置或修改 `redis.windows-service.conf` 添加 `requirepass ruoyi123`
2. 前端端口已改为8081，如需改回80需以管理员权限运行
3. Maven镜像已改为阿里云公共仓库，如需使用私有仓库需恢复原settings.xml配置
4. 后端启动约需60-130秒，请耐心等待日志输出 "Started DromaraApplication"
5. 如遇8080端口占用，先停止已有Java进程再启动
